# 💰 T10: Pressupost del projecte

## 📖 Introducció

En el desenvolupament d’un projecte tecnològic professional, la qualitat tècnica no és suficient per si sola.

Una solució només és viable si va acompanyada d’un **pressupost clar, realista i transparent**.

Com a empresa de serveis informàtics, presentem a **FoodLogístic S.A.** una proposta econòmica que reflecteix:

* 🔧 El cost real d’implantació del sistema.
* 🔁 Els costos recurrents de manteniment.
* ⏱️ L’esforç tècnic necessari.
* 📊 La viabilitat econòmica del projecte.

---

# 🧾 1. Cost d’implantació (pagament únic)

Aquest apartat inclou tots els costos inicials necessaris per posar en marxa el projecte.

---

## 🖥️ 1.1 Maquinari i programari

### Infraestructura

* VPS inicial per desplegament de serveis.
* Configuració de servidor web i base de dades.
* Instal·lació i configuració de serveis.

💰 Cost estimat VPS inicial: **6 €/mes (proporcional a implantació)**

---

## 🔐 1.2 Llicències inicials

En aquest projecte s’utilitzen principalment eines open source:

* Moodle (LMS) → gratuït
* Nginx → gratuït
* Ubuntu Server → gratuït
* MariaDB → gratuït

👉 Per tant, el cost de llicències inicials és:

💰 **0 €**

---

## 👨‍💻 1.3 Honoraris professionals

Per calcular el cost de mà d’obra, s’ha utilitzat una referència de mercat per a tècnics IT junior/consultors:

💲 Preu mitjà estimat: **25 €/hora**

---

## ⏱️ Estimació d’hores

| Tasca                                | Hores estimades |
| ------------------------------------ | --------------- |
| Instal·lació servidor i configuració | 10 h            |
| Configuració LMS (Moodle)            | 12 h            |
| Implementació web corporativa        | 8 h             |
| Seguretat i backups                  | 5 h             |
| Documentació tècnica                 | 6 h             |
| Proves i ajustos finals              | 4 h             |

### ⏳ Total hores: **45 h**

---

## 💰 Càlcul final d’implantació

| Concepte                | Cost    |
| ----------------------- | ------- |
| Maquinari (VPS inicial) | 6 €     |
| Llicències              | 0 €     |
| Mà d’obra (45h × 25€)   | 1.125 € |

### 🧾 Total implantació: **1.131 €**

---

# 🔁 2. Costos recurrents (mensuals)

Aquest apartat inclou els costos necessaris per mantenir el sistema operatiu.

---

## ☁️ 2.1 Plataformes SaaS

Per a FoodLogístic S.A. es proposa l’ús de:

### Microsoft 365 Business Basic

* Correu electrònic corporatiu
* Teams
* OneDrive

💰 Cost aproximat: **6 €/usuari/mes**

👥 45 usuaris:

👉 45 × 6 € = **270 €/mes**

---

## 🌐 2.2 Hosting i domini

* VPS producció
* Domini corporatiu
* Certificat SSL

💰 Cost estimat:

* VPS: 6 €/mes
* Domini: 1 €/mes (equivalent anual)
* SSL: gratuït (Let’s Encrypt)

### Total hosting:

👉 **7 €/mes**

---

## 🛠️ 2.3 Suport i manteniment

Inclou:

* Còpies de seguretat.
* Actualitzacions de seguretat.
* Resolució d’incidències.
* Monitorització del sistema.

💰 Quota tècnica estimada:

👉 **120 €/mes**

---

## 💰 Cost total recurrent mensual

| Concepte      | Cost  |
| ------------- | ----- |
| Microsoft 365 | 270 € |
| Hosting       | 7 €   |
| Manteniment   | 120 € |

### 🧾 Total mensual: **397 €/mes**

# 🧠 4. Justificació de la proposta

## 📌 Origen dels preus

Els preus utilitzats s’han basat en:

* Tarifes reals de mercat de serveis IT junior.
* Preus públics de Microsoft 365.
* Costos estàndard de VPS europeus.
* Referències de serveis cloud habituals.

---

## 🎯 Criteris de selecció

### 💰 Cost

S’ha prioritzat una solució econòmica però professional.

### ⚙️ Tecnologia

* Eines open source per reduir costos.
* SaaS per millorar productivitat.

### 📈 Escalabilitat

El sistema permet augmentar recursos segons creixement.

### 🌱 Sostenibilitat

* Infraestructura virtualitzada.
* Reducció de maquinari físic.
* Consum optimitzat.
