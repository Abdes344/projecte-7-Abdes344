# 🌐 P02: Web corporativa

## 📖 Introducció

A la tasca 8 es va seleccionar la proposta definitiva de pàgina web corporativa que es presentarà al client **FoodLogístics S.A.**.

Aquesta activitat consisteix a **desplegar la solució final** perquè sigui accessible públicament mitjançant **GitHub Pages**.

L’objectiu és simular un entorn professional real on la web del client està publicada i operativa.

---

# 🎯 Objectius de la tasca

* Desplegar una web corporativa funcional.
* Utilitzar Git i GitHub com a sistema de control de versions.
* Publicar el projecte amb GitHub Pages.
* Organitzar correctament el repositori.
* Treballar amb flux de desenvolupament professional.

---

# 🗂️ Estructura del repositori

El repositori ha d’anomenar-se:

```
web_projecte7
```

---

## 📁 Estructura obligatòria

```plaintext
📦 web_projecte7
 ┣ 📄 README.md
 ┣ 📁 docs
     ┣ 📄 index.html
     ┣ 📄 styles.css
     ┣ 📄 script.js (opcional)
     ┣ 📁 images
```

---

# 🧾 1. README.md

## 📌 Contingut obligatori

El fitxer `README.md` ha d’incloure:

* 📖 Descripció del projecte.
* 🎯 Objectiu de la web corporativa.
* 🧩 Explicació de l’estructura.
* 👥 Autors del projecte.
* 🔗 Enllaç final a GitHub Pages.

---

## ✍️ Exemple d’estructura

```markdown
# 🌐 Web corporativa FoodLogístics

## 📖 Descripció
Projecte de desenvolupament de la web corporativa per a l’empresa FoodLogístics S.A.

## 🎯 Objectiu
Substituir la web actual per una solució moderna, accessible i optimitzada.

## 📁 Estructura
- docs/index.html
- docs/styles.css

## 🚀 Deploy
https://usuari.github.io/web_projecte7
```

---

# 💻 2. Carpeta /docs

## 📌 Funció

La carpeta `/docs` conté tota la web que es desplegarà amb GitHub Pages.

---

## 📄 Contingut mínim

### 🌐 index.html

* Pàgina principal.
* Estructura clara i semàntica.
* Informació de l’empresa.
* Navegació funcional.

---

### 🎨 styles.css

* Disseny visual de la web.
* Identitat corporativa coherent.
* Disseny responsive (opcional però recomanat).

---

### 🖼️ images/

* Logotips.
* Imatges corporatives.
* Recursos visuals de la web.

---

# 🚀 3. Desplegament amb GitHub Pages

## ⚙️ Passos a seguir

1. Fer commit de tots els canvis.
2. Pujar el repositori a GitHub.
3. Anar a **Settings** del repositori.
4. Accedir a **Pages**.
5. Configurar:

   * Source: `Deploy from branch`
   * Branch: `main`
   * Folder: `/docs`

---

## 🌍 Resultat final

La web serà accessible a través d’una URL del tipus:

```
https://usuari.github.io/web_projecte7
```
