# 📁 P03: Repositori personal

## 📖 Introducció

En aquesta fase del projecte es treballa la consolidació de l’ús de **Git i GitHub com a eina de control de versions**, aplicant una estructura professional de repositori.

L’objectiu és assegurar que el repositori personal estigui correctament organitzat i preparat per al lliurament final del projecte.

Aquest sistema simula el flux real de treball utilitzat en entorns professionals de desenvolupament de programari.

---

# 🎯 Objectius de la tasca

* 📌 Organitzar correctament el repositori del projecte.
* 📁 Aplicar una estructura coherent per carpetes.
* 🧾 Crear documentació en format Markdown.
* 💻 Utilitzar Git com a eina de control de versions.
* 🚀 Preparar el repositori per al lliurament via GitHub Classroom.

---

# 🗂️ Estructura obligatòria del repositori

Cada projecte i activitat ha d’estar organitzada en carpetes separades segons el seu tipus:

```plaintext id="repo1"
📦 projecte
 ┣ 📁 T01
 ┣ 📁 T02
 ┣ 📁 T03
 ┣ 📁 P01
 ┣ 📁 P02
 ┣ 📁 P03
```

---

# 📄 Contingut obligatori dins de cada carpeta

## 🧾 1. README.md

Cada carpeta ha de contenir obligatòriament un fitxer:

```plaintext id="file1"
README.md
```

### 📌 Contingut del README.md

El fitxer ha d’incloure:

* 📖 Descripció de l’activitat.
* 🧠 Resum de l’enunciat.
* 🧩 Explicació breu del que s’ha fet.
* 🔗 (Opcional) Enllaços o recursos utilitzats.

### ✍️ Format obligatori

* Markdown (`.md`)
* Estructurat en seccions clares
* Amb títols i subtítols

---

## 🧾 2. solucio.md

Cada activitat ha d’incloure també:

```plaintext id="file2"
solucio.md
```

### 📌 Contingut del fitxer

* Codi utilitzat (si n’hi ha)
* Explicacions tècniques
* Enllaços a recursos o repositoris externs
* Configuracions importants

---

## 🖼️ 3. Carpeta d’imatges

Si el projecte ho requereix:

```plaintext id="imgfolder"
/images
```

### 📌 Contingut

* Captures de pantalla
* Diagrames
* Evidències del treball realitzat

---

# ⚙️ Bones pràctiques amb Git

## 🔁 Control de versions

* Commits freqüents i clars
* Missatges descriptius:

  * `Afegit README T01`
  * `Estructura inicial del projecte`
  * `Afegida solució P02`

---

## 🌿 Organització del repositori

* No barrejar activitats dins la mateixa carpeta.
* Mantenir una estructura neta i previsible.
* Evitar fitxers duplicats o desorganitzats.

---

# 🚫 Restriccions importants

## ❌ No s’accepta

* Lliuraments fora de GitHub Classroom.
* Repositoris personals no assignats.
* Estructures desorganitzades o incompletes.

---

# 🎯 Objectiu final

L’objectiu d’aquesta tasca és demostrar que l’estudiant és capaç de:

* Gestionar un repositori de manera professional.
* Organitzar projectes de forma estructurada.
* Utilitzar Git com a eina de treball real.
* Preparar un lliurament correcte en entorn empresarial simulat.

---

# 🏁 Conclusió

Un repositori ben estructurat és la base del treball en equip i del desenvolupament professional.

Aquesta tasca assegura que el projecte compleix els estàndards mínims de qualitat, organització i traçabilitat necessaris en entorns de desenvolupament moderns.
