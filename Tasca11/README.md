
# 🌐 T11: Preparem una intranet per a més endavant – Aplicacions web

## 📖 Breu descripció

En aquesta pràctica es treballa la preparació d’una **intranet corporativa basada en WordPress**, orientada a un entorn empresarial real.

El projecte simula la implantació d’una plataforma interna per a una empresa de serveis informàtics que necessita centralitzar la comunicació i la gestió documental.

---

## 🎯 Objectius de la tasca

El client necessita una solució que permeti:

* 📂 Compartir documents entre treballadors.
* 📝 Treballar amb documents en línia.
* 📧 Gestionar correu electrònic des d’un entorn centralitzat.
* 📅 Organitzar calendaris i tasques.
* 🌐 Accedir a tota la informació des d’un únic portal web.

---

# 🧩 Solució proposada

La solució es basa en la creació d’una **intranet amb WordPress**, ampliada amb plugins específics per convertir-la en un entorn de treball col·laboratiu.

---

## ⚙️ Arquitectura de la intranet

### 🔹 Base del sistema

* WordPress (CMS principal)
* Apache o Nginx com a servidor web
* PHP + MySQL/MariaDB

---

### 🔹 Funcionalitats afegides amb plugins

| Funcionalitat       | Plugin / eina                      |
| ------------------- | ---------------------------------- |
| Gestió de documents | Document Library / WP File Manager |
| Correu electrònic   | Integració SMTP + plugins de mail  |
| Calendaris          | The Events Calendar                |
| Tasques             | Project management plugins         |
| Intranet privada    | Members / Restrict Content         |

# ⚠️ Problemes trobats i solucions

## 🧱 Problema 1: Errors en la instal·lació de plugins

### Problema:

Alguns plugins no eren compatibles amb la versió de WordPress.

### Solució:

* Actualització del CMS.
* Substitució per plugins alternatius.

---

## 🔐 Problema 2: Accés restringit incorrecte

### Problema:

Usuaris no autoritzats podien veure contingut intern.

### Solució:

* Configuració de permisos amb plugin de restricció.
* Revisió de rols d’usuari.

---

## ⚡ Problema 3: Rendiment del sistema

### Problema:

La intranet carregava lentament amb diversos plugins actius.

### Solució:

* Optimització de plugins.
* Eliminació d’elements innecessaris.
* Activació de cache.
