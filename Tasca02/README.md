# 🌐 T02: Creant la proposta de pàgina corporativa 💻

## 🚀 Introducció

L’empresa **FoodLogistic S.A.** 🏭🍎 necessita millorar la seva presència digital. La seva web actual està desactualitzada, no compleix normativa i ofereix una mala experiència d’usuari.

👉 L’objectiu és crear una **web corporativa moderna, funcional i publicada realment a Internet** 🌍

---

## 🎯 Objectius del projecte

- 🌍 Publicar la web amb **GitHub Pages**
- 📄 Crear un README.md professional
- 📊 Integrar analítica amb **StatCounter**
- 🔐 Complir normativa:
  - LOPDGDD (protecció de dades)
  - LSSI-CE (serveis digitals)
